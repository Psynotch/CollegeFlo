# CampusFlow

CampusFlow is a student productivity app built with **Flutter** and powered by **Firebase**.  
It helps students manage their academic life by providing a clean, real‑time interface for:

- 📅 **Timetable Management** – View daily schedules with subject, room, and time details.
- ✅ **Attendance Tracking** – Mark classes as attended/missed with instant Firestore sync.
- 🔄 **Reset Option** – Correct mistakes easily with a dedicated reset button.
- 📝 **Assignments Tab** – Track assignments with deadlines and completion status.
- 📚 **Exams Tab** – Manage exam schedules and receive timely reminders.
- 📌 **Events Tab** – Stay updated on campus events and activities.
- 🎨 **Minimal UI** – Color‑coded feedback (green check, red cross, grey question) for clarity.
- 🔐 **Secure Authentication** – Firebase Auth ensures per‑student data siloing.
- ⚡ **Real‑Time Sync** – Firestore streams keep data updated instantly across devices.

---

## 🚀 Current Status
- ✅ MVP ready with Android support.
- 👤 Single‑user demo mode (currently supports only one student).
- 📱 iOS deployment planned for future releases.
- 🏫 Future roadmap includes integration with official college APIs for automated data sync.

---

## 🛠️ Tech Stack
- **Frontend:** Flutter SDK, Material Design
- **Backend:** Firebase Authentication, Cloud Firestore, Cloud Functions
- **Other:** Firebase Analytics (optional), Firebase Cloud Storage

---

## 🌟 Future Development
- Multi‑student support with UID‑based Firestore siloing.
- iOS deployment and App Store release.
- Push notifications for classes, assignments, exams, and events.
- Attendance analytics dashboard with bunkable class insights.
- Faculty portal for teachers to manage attendance and assignments.
- Integration with official college APIs for seamless data sync.
- Play Store release for wider accessibility.
